Datos abiertos

Todo, sin filtrar.

Lo que ves en la web es una selección. Aquí está la base de datos entera, para que cualquiera pueda comprobar, corregir o reutilizar el trabajo.

Descargas

Se regeneran cada vez que se actualiza el archivo. Licencia CC BY 4.0: puedes usarlos para lo que quieras citando «Archivo del discurso político».

  • archivo.sqlite.gz: la base de datos completa (SQLite). Todas las intervenciones de todas las apariciones, también las de periodistas y hablantes sin identificar, con la decisión de la huella de voz y su similitud; las frases del juego con su puntuación; todas las afirmaciones extraídas, ataques, posibles contradicciones, comprobaciones de atribución y tono.
  • claims.csv: las afirmaciones (promesas, cifras, ataques, posturas) en una hoja de cálculo, con enlace a la fuente en el segundo exacto.
  • items.tar.gz: un JSON por aparición, tal como lo produce la cadena de procesado.
  • review/: las revisiones humanas: contradicciones descartadas y por qué, y la muestra de atribución revisada frase a frase.
  • LEEME.txt: qué significa cada tabla y cada columna.

API

Una API de solo lectura en https://gerritsxd.com/discurso/api/, en JSON:

  • search?q=vivienda&person=feijoo&all=1: búsqueda de texto completo (all=1 incluye a todos los hablantes)
  • claims?type=promesa&topic=vivienda&person=sanchez, contradictions, attacks, tone, analysis
  • item/<id>: una aparición completa; stats

Qué no se publica

  • Audio y vídeo: son de sus autores; cada frase enlaza al original.
  • Las huellas de voz: son datos biométricos.
  • Las respuestas del juego de hoy (las de días pasados sí).

El código que genera todo esto, incluidas las instrucciones exactas que recibe el modelo de lenguaje, está en GitHub.
